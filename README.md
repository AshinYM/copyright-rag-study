## 비용과 검증

임베딩·답변·평가 셀은 외부 API를 호출하며 비용이 발생합니다. 코드를 먼저 검토하고 개인 키·모델·호출 규모를 정한 뒤 실행하세요. API 모델명은 과거 설정이며 현재 이용 가능 여부를 확인해야 합니다. 이번 정리에서 유료 API를 호출하지 않았습니다.

별도 `historical-results.md`는 기존 소수 문항 평가 기록이며 재실행 결과가 아닙니다. 검색 다양성 개선과 정답 근거 순위·답변 사실성은 별개입니다. 다음 개선은 정답 판례가 검수된 질문 세트, retrieval 지표, 기법별 ablation, API 없이 실행하는 검색 검사입니다. 법률 자문 서비스가 아닙니다.

이 저장소는 기존 학습·팀 프로젝트에서 포트폴리오 후보를 선별한 **비공개 검토본**입니다. 원본 코드의 작성 기여와 교육 제공 코드의 재배포 허용 범위는 아직 확인되지 않았습니다. 공개 전 작성자·팀의 동의와 데이터 이용 조건을 확인해야 합니다. 임의의 오픈소스 라이선스를 부여하지 않았습니다.

교안·녹취록·실제 데이터·모델 파일·DB·API 키·실행 출력은 포함하지 않습니다. 노트북 출력은 제거했습니다. 과거 결과는 이번 재실행 결과가 아닙니다.
